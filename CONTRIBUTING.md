# Contributing

This repository is a place to practice small, understandable changes.

## Before you start

- Check existing issues and pull requests to avoid duplicating an exercise.
- Choose a focused task, such as clarifying a command or adding a useful example.
- Create a branch from the latest `main`. See [WORKFLOW.md](WORKFLOW.md) for the full sequence.

## Before opening a pull request

- Read the diff and remove unrelated changes.
- Run any checks relevant to your change; for documentation, verify commands and links.
- Describe what changed and how you checked it. Link a related issue if one exists.
- Do not include credentials, tokens, or private data in commits, issues, or screenshots.

Once merged, update your local default branch and delete the exercise branch when you no longer need it.
